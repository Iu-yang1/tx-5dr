# TX-5DR v1.0.5

## Manual QSO completion logging

- Fix the standard digital QSO runtime's manual final-message selection: choosing **TX4 (RR73)** or **TX5 (73)** now prepares the same declarative QSO completion effect used by automatically selected final messages.
- Preserve the existing single-writer logbook persistence, QSO lifecycle identity, completion settlement, and deduplication. Repeated selections or decisions cannot create a second completion for the same contact.
- Retain the durability guard before a subsequent operator handoff. If the first logbook write has not settled, the next caller is not activated in the same decision batch; a later directed call remains eligible through silent listening.
- Add regression coverage for manual RR73/73 in FT8 and FT4, absent target callsign, and duplicate completion prevention, plus the pending-write handoff boundary.

## Scope and validation

The standard-QSO runtime is shared with supported strategy-driven native digital operation; however, mode-specific paths and manually confirmed logbook entry flows should be validated separately. WSPR beacons are not QSOs and do not create automatic QSO logs.

No physical radio transmission or device-specific logging behavior was validated by the release automation. GitHub Actions test and artifact results are the software acceptance evidence.
