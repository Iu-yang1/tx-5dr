# TX-5DR v1.0.6

## Changes

- Integrate `boybook/tx-5dr` upstream main through `1567446b103b69ae34f9bae7cc7a6faeeaf802b6` with an authentic two-parent Git merge.
- Add upstream RTTY keyboard mode, AFSK transmission, decoder, receiver controls, message panels, and station simulation support; integrate the feature with this fork's engine lifecycle and RadioBridge.
- Adopt Hamlib worker IPC message filtering, desktop preload subscription disposal, startup diagnostics improvements, translation and build-tool changes.
- Refresh Electron and runtime dependencies, regenerate the Yarn 4 lockfile, and use Plugin SDK 2.8.0 within the monorepo (independent SDK/npm publication is not included).
- Retain the existing FTDX10 CAT, PTT recovery, FT8/FT4 receiver-scoped callsign hash memory and manual RR73/73 completion persistence.

## Scope and validation

- Host release: Windows x64 / Linux x64 / Linux ARM64 desktop, Linux Server and Docker, through the repository's official workflows.
- Hardware-specific CAT, transmitted AFSK/PCM quality, RF output, radio timing and on-air log persistence require real-station validation. Repository simulation and CI are not over-the-air evidence.
- The upstream CW log UI wrapper refactor was not substituted for this fork's existing behavior; the shared keyboard-mode components and RTTY UI are integrated separately.
- Android APK, independent npm Plugin SDK and site deployment are not part of this Host release.
